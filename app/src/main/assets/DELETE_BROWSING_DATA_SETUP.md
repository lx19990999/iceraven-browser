# 🗑️ 默认退出时删除浏览数据配置

## 📋 **实现的功能**

配置浏览器默认在退出时删除所有浏览数据，包括：

### ✅ **默认启用的数据清理项目**

1. **📱 打开的标签页** - 清除所有打开的标签页
2. **📚 浏览历史** - 删除访问过的网站记录
3. **🍪 Cookies和网站数据** - 清除登录状态和网站存储数据
4. **🖼️ 缓存的图片和文件** - 释放存储空间
5. **🔐 网站权限** - 重置所有网站权限设置
6. **📥 下载历史** - 清除下载记录（文件本身保留）

## 🔧 **技术实现**

### 1. 主开关设置
**文件**: `app/src/main/java/org/mozilla/fenix/utils/Settings.kt`
```kotlin
var shouldDeleteBrowsingDataOnQuit by booleanPreference(
    appContext.getPreferenceKey(R.string.pref_key_delete_browsing_data_on_quit),
    default = true, // 默认启用退出时删除浏览数据
)
```

### 2. 各项数据类型默认值
**文件**: `app/src/main/java/org/mozilla/fenix/utils/Settings.kt`
```kotlin
fun getDeleteDataOnQuit(type: DeleteBrowsingDataOnQuitType): Boolean =
    preferences.getBoolean(type.getPreferenceKey(appContext), true) // 默认删除所有数据类型
```

### 3. XML配置文件
**文件**: `app/src/main/res/xml/delete_browsing_data_quit_preferences.xml`

为所有选项添加了 `android:defaultValue="true"`：
- 主开关：`SwitchPreference` 默认启用
- 所有子选项：`CheckBoxPreference` 默认全部选中

### 隐私保护增强
- **完全清理**: 退出时自动清除所有浏览痕迹
- **无需手动**: 用户无需记住手动清理数据
- **彻底保护**: 确保隐私数据不会残留

### 使用场景
- **共享设备**: 在公共或共享设备上使用
- **隐私浏览**: 需要高度隐私保护的场景

### 灵活配置
- **可选择性**: 用户仍可单独关闭某些数据类型的清理
- **完全控制**: 可以完全关闭退出时删除功能
- **即时生效**: 设置更改立即生效

## ⚠️ **重要提醒**

### 数据丢失风险
- **登录状态**: 所有网站的登录状态将丢失
- **个性化设置**: 网站的个人偏好设置将被重置
- **浏览历史**: 无法恢复已删除的浏览记录

### 建议用法
- **同步账户**: 建议启用Firefox同步来保存重要数据
- **书签备份**: 重要网站建议添加到书签
- **密码管理**: 使用密码管理器保存登录信息

## 🔄 **工作流程**

1. **用户退出**: 用户选择"退出"菜单项
2. **数据检查**: 系统检查哪些数据类型需要删除
3. **批量清理**: 并行执行所有启用的数据清理操作
4. **应用退出**: 清理完成后正常退出应用

## 📊 **清理范围详解**

### 打开的标签页
- 关闭所有普通标签页
- 关闭所有隐私标签页
- 清除标签页状态

### 浏览历史
- 删除访问记录
- 清除搜索历史
- 移除频繁访问的网站

### Cookies和网站数据
- 清除所有Cookie
- 删除本地存储数据
- 清除会话存储
- 重置网站数据

### 缓存文件
- 删除图片缓存
- 清除CSS/JS缓存
- 移除其他临时文件

### 网站权限
- 重置位置权限
- 清除通知权限
- 重置摄像头/麦克风权限
- 清除其他网站权限

### 下载历史
- 清除下载记录
- 保留实际下载的文件
